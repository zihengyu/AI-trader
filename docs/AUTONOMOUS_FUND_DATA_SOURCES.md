# AI 模拟基金：数据源与升级路线

本应用用到的每个数据源、它们的局限，以及 Yahoo 不够用时可以接入什么。

**Last Updated:** 2026-11-03

**Status:** 免费数据源已接入并有离线测试；真实网络访问需在部署服务器上用 `check` 验证

**Audience:** 运营者，以及为 `scripts/autonomous_fund/` 增加数据源的贡献者

## Overview

专业量化和这套系统的最大差距之一在数据：点时（point-in-time）基本面、包含已退市公司的历史、
有服务等级保障的行情、事件日历。本文说明现在用什么、各自的边界，以及按成本从低到高的升级选项。
新增数据源必须遵守仓库的第一条规则：**缺数据就空着，绝不编造、补齐或沿用旧价格**（见 `docs/BACKTESTING_ARCHITECTURE.md`）。
所有数据源都接在本应用里，不修改 LumiBot 核心。

## 现在用的数据源

| 数据 | 来源 | 用途 | 局限 |
|---|---|---|---|
| 实时报价、分钟线、日线（local 模式） | Yahoo（非官方接口，推送＋下载） | 本地撮合、风控历史、因子 | 没有服务保障，会限流；大陆服务器通常无法访问；不含已退市股票 |
| 行情与成交（paper 模式） | Alpaca Paper | 券商撮合、账户 | 免费账户的实时行情来自单一交易所（IEX），历史 SIP 数据有 15 分钟延迟限制 |
| 日线备用源（local 模式） | Alpaca 历史行情 API | Yahoo 失败时的风控和因子历史（`risk_history_fallback`） | 需要 Alpaca Key；本地撮合和分红拆股仍用 Yahoo |
| 财报基本面 | SEC EDGAR XBRL company facts | 因子实验室的盈利、营收、毛利、经营现金流、净资产、总资产、股本 | 只有美国上市公司；按 `filed` 日期做点时；多类别股的股数为空；需要 `FUND_SEC_USER_AGENT` |
| 8-K 公告、新闻 | SEC、Yahoo、Google News、美联储 RSS | AI 的资讯上下文 | 标题级信息，不保证完整；内容按不可信数据处理 |
| 宏观环境 | FRED | 美债收益率、曲线、高收益债利差、VIX | 市场类序列不修订，可用于回测；经济数据（如 CPI）有修订，本应用没有使用 |
| 财报日历 | Finnhub（有 Key 时）或 Yahoo 日历 | 财报前降仓 | 日期偶有变动；拿不到不猜测；只在 local／paper 生效 |
| 经济日历 | FRED 发布日历（`releases/dates`，需要 `FRED_API_KEY`） | 数据员整理未来三周 CPI、非农、GDP、PCE、PPI、零售、初请、FOMC 等公布日期 | 只有日期没有具体时刻；按发布名称筛选，FRED 改名会漏掉，需要时补充名单 |
| 盘前行情、全球市场 | Yahoo（含盘前盘后的分钟线；股指期货、VIX、10 年期收益率、美元指数、欧元、日元、原油、黄金、日经、恒生、欧洲斯托克 50） | 数据员给盘前研究和盘中决策的背景 | 非官方接口；盘前成交稀少；期货和外汇的“涨跌”是相对上一个纽约日的最后一根 K 线 |

`check` 命令会逐项探测这些服务能否连通（见 `docs/AUTONOMOUS_FUND_UBUNTU.md`）。

## Yahoo 的问题和对策

1. **不稳定、会限流**：已有对策——每个证券每天只下载一次日线、单飞请求、失败退避、Alpaca 日线备用源。
   限流时风控把缺历史的证券视为“不能加仓”，不会用旧数据下单。
2. **大陆服务器访问不了**：把服务器放在境外地域，或设置 `HTTPS_PROXY`。
3. **没有已退市股票**：研究股票池是“今天的大盘股”，因子回测有幸存者偏差（会高估动量、低估风险）。
   只有付费的含退市数据库能解决，见下文。
4. **不是点时数据**：Yahoo 的基本面是最新值，用于历史会有前视。本应用的基本面只用 SEC，不用 Yahoo。

## 升级选项（按成本从低到高）

| 选项 | 解决什么 | 接入方式 |
|---|---|---|
| Finnhub 免费 Key | 更可靠的财报日历 | 已接入：在 `.env` 设 `FINNHUB_API_KEY` |
| FRED 免费 Key | 官方 API，限额更高；经济日历必需 | 已接入：设 `FRED_API_KEY` |
| Alpaca 付费行情订阅（SIP 实时） | 全市场实时报价、无延迟历史 | paper 模式直接受益；local 模式的实时报价仍用 Yahoo，需要新增报价适配器 |
| Polygon.io 股票订阅 | 有服务保障的实时和历史 SIP 行情、拆股分红、参考数据 | LumiBot 已有 Polygon 回测数据源；local 模式需要新增报价和日线适配器 |
| Tiingo | 便宜的日线和基本面 | 可作为日线备用源，按 `history.py` 的接口实现 |
| Sharadar（Nasdaq Data Link）核心美股基本面与价格 | **点时基本面＋包含已退市公司的历史**，消除幸存者偏差，是个人量化常用的专业数据 | 在 `fundamentals.py` 旁实现同样的 `panels(symbols, index)` 接口；研究股票池可改为历史成分 |
| DataBento、ThetaData | 机构级逐笔／分钟数据；ThetaData 还有期权 | LumiBot 已支持回测（ThetaData 只走 Data Downloader，规则见 `AGENTS.md`）；本应用目前不交易期权 |
| 分析师一致预期（I/B/E/S、FactSet 等） | 盈利意外、预期修正类因子 | 价格昂贵，需要单独授权和合同 |

**建议顺序**：
1. 现在（免费）：Yahoo＋Alpaca 备用日线＋SEC＋FRED＋Finnhub 免费 Key。只要部署在能访问这些服务的地域，已能运行全部功能。
2. 想让因子研究更可信：Sharadar 一类含退市的点时数据库（解决幸存者偏差），再把研究股票池扩大到几百只。
3. 想让行情更可靠：Alpaca 付费 SIP 或 Polygon，并为 local 模式实现对应的报价适配器。
4. 将来接 Schwab 实盘（需要你单独明确授权）：报价和成交以券商为准，其余数据源不变。

## 为本应用增加数据源的规则

- 每个源实现成独立模块，可注入 HTTP 客户端，测试只用合成数据，不访问网络；`check` 增加对应探测。
- 历史数据必须标明可得时间：行情只用已完成的 K 线；基本面只用受理日期早于当天的报告；事件日历在回测中不使用当天才知道的版本。
- 失败时返回“不可用”并记录事件，绝不补数、插值或沿用旧值；风控把缺数据视为不能加仓。
- Key 只从 `.env` 读取，输出和日志里不出现 Key 或带 Key 的 URL；新变量同时写进 `.env.example`、`settings.py`、
  `docs/ENV_VARS.md` 和 `docsrc/environment_variables.rst`。
